# Quiz Exam System

A simple Python-based Quiz Exam System that uses file handling to store and manage quiz questions.

## Features

- Start a quiz
- Display questions one by one
- Multiple-choice questions
- Check answers and calculate score
- Add new questions
- View all questions
- Search questions using keywords
- Store questions in a text file
- Handle invalid input using exception handling
